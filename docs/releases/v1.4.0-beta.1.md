# ASCEND v1.4.0-beta.1

Pre-release for testing, approved by the project lead on 22 November 2026. This is not a stable promotion and has not passed a three-day beta period.

## What is included

This minor-version beta collects the work since v1.3.0, rather than calling the whole interval a patch:

- Training-week scheduling, a 10-minute session option, lock-screen workout entry and opt-in desktop habits.
- Chat plan-building with reviewed changes, specialist trainer handoffs and local knowledge answers with sources. Expanded exercise/practice notes and South Indian food entries.
- Intent-router fallback for messages the deterministic rules cannot confidently handle. Low-confidence and pain answers remain bounded; a model score is not evidence of clinical quality.
- Profile trophy shelf and replayable unlocks.
- Confirmed/undone chat-action state now survives switching Chat views.
- Packaged-photo fix: local image decoding works without enabling remote image origins.
- Academic review materials in docs/college-docs, with proposed studies distinguished from completed evidence.

## Installation and requirements

Use `ASCEND-Setup-1.4.0-beta.1.exe` attached to the GitHub pre-release, and compare its SHA-256 against the attached `SHA256SUMS.txt`. The stable/latest download remains v1.3.0. The build is unsigned and Windows SmartScreen can warn. Existing users should make a backup before installing; local data is retained under the app's normal data folder.

The release automation builds and smoke-tests the Windows frozen sidecar, builds the NSIS installer, checks Electron fuses, then attaches the installer and SHA-256 sums. This is not the same as manually installing the app and checking every feature on a Windows PC.

## Verification and limits

The source changes passed 614 frontend tests and a Linux production build. An unpacked Linux Electron app with frozen Python sidecar and real IPC was exercised using fictional data. Covered flows include onboarding, chat confirmation/undo, manual strength log/edit/delete/finish/history, meal logging, weigh-ins and measurements, planner save/follow, custom exercises, progress-photo upload/delete, import preview/confirmation/deduplication, serialized exports, backup/restore and data erase.

A real Windows install/uninstall, Windows login/tray/notification integration, every timed/hold/cardio path, every settings permutation, real Ollama inference, native save dialogs, video/share outputs and real team-DB upgrade rehearsal remain untested. No claim is made that every function works or that the app is clinically validated. Food-photo recognition remains hidden without a trained approved model.

Existing 22 frontend lint warnings and 14 moderate development-tool dependency advisories remain. The two high development-tool advisories found during this review were removed with compatible lockfile updates; the checked runtime dependency audit had no advisories.

## Schema, formula and model notes
