# ASCEND 0.3.0 release notes

Released 2026-10-20 from `main`, tag `v0.3.0`. Full list of changes: [CHANGELOG](../../CHANGELOG.md#030---2026-10-20).
Merged pull requests: #17 to #25.

## Highlights

- **Import & export screen.** Bring your history over from Strong or Hevy with a preview
  before anything is written. Re-importing the same file is safe.
- **Coach reply checks.** A local-AI reply that invents a number, mentions a medicine or a
  dose, diagnoses, or claims to have changed your plan is swapped for the rule-based tip.
- **States and accessibility.** Every screen has loading, empty and error states, and the
  app is usable with the keyboard in both themes.
- **Backups in the engine.** Manual backup, list and restore, plus an automatic backup
  before an update migrates the database. The Settings screen for backups is not built yet.

## Upgrade notes

| Item | Value |
|---|---|
| Database schema | `0007` → `0009` (0008 event outbox, 0009 workout source and import key) |
| Automatic backup | Taken before the migration runs; the newest 5 automatic copies are kept |
| Formula versions | Engine formulas unchanged from 0.2.0; new: coach reply validator `validate-1.0.0`, backup format 1 |
| Model manifest | No food model ships; the ML pipeline's manifest keeps `min_app_version` 0.2.0 |
| API change | Request bodies with unknown fields now get a 422 (PUT /profile still ignores extras) |

Checked for this release, on Linux: a database created at schema `0007` was opened by the
0.3.0 sidecar, which wrote a pre-migration backup tagged `0007` and then migrated to
`0009`. Manual backup, list and restore were run end to end against a running sidecar
(a set logged after the backup was gone after restoring it, and a safety copy was saved).

## Known issues

- **Windows installer not yet run on Windows.** The NSIS configuration and the frozen
  sidecar were built and smoke-tested on Linux only. The installer is unsigned, so Windows
  SmartScreen will warn on first run ("More info" → "Run anyway").
- **No backup screen yet.** Backups are available through the engine API only.
- **Backup passwords are not supported yet**; a request with a password gets a 422.
- **No food recognition model.** The ML pipeline runs end to end on synthetic smoke data;
  no trained food model ships in this release.
- CI workflows are defined but have not run on GitHub yet for this release.
