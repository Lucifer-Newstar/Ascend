# ASCEND 1.0.0 release notes

Released 2026-10-23 from `main`, tag `v1.0.0`. This is the first stable release of ASCEND, an
offline Windows desktop fitness RPG. Full list of changes: [CHANGELOG](../../CHANGELOG.md#100---2026-10-23).

## Highlights

- **Train with a plan, not a guess.** A keyboard-first logger pre-fills your next set, and the
  progression engine (`prog-v1`) suggests the target with a "Why?" for every number. Four built-in
  programs (full body, upper/lower, push/pull/legs, home) follow what you actually log.
- **See every muscle.** A detailed map of 54 muscles and heads, front, back and a deep layer, shows
  what is recovered, recovering, over- or under-trained, from per-muscle recovery (`recovery-v2`)
  with personal recovery factors.
- **Eat to a target that learns.** Log Indian meals in katori and piece portions. An adaptive TDEE
  (`tdee-v1`) learns your real expenditure from weigh-ins and meals; weekly insights point out what
  to change.
- **Play the long game.** XP, ranks E→S, daily quests, streak freezes, calisthenics skill trees and
  a weekly boss raid. Instructor Iskra Vey delivers your briefing, or switch to the plain System
  style.
- **Your data stays yours.** Everything runs on your PC. No account, no cloud, no telemetry. Daily
  automatic backups, restore with a database check, and export to JSON or CSV.
- **Optional local AI.** With Ollama and `qwen3:4b` the coach can phrase explanations, but it only
  rephrases what the engines computed. A reply that changes a number is replaced by the rule-based
  text. The app is fully usable without it.
- **Hardened.** Every fix from the October 2026 security review is in, on Electron 45 with all
  Electron fuses set and checked in CI (details below).

## Install

1. Download **`ASCEND-Setup-1.0.0.exe`** from the assets below.
2. Run it. The installer is **not code-signed**, so Windows SmartScreen shows "Windows protected
   your PC". Click **More info**, then **Run anyway**.
3. Choose a folder (default `%LOCALAPPDATA%\Programs\ASCEND`; no admin rights needed) and finish.
   ASCEND opens with a five-step first run.

**Upgrading** from an earlier version: run the new installer over the old one. Your data in
`%APPDATA%\ASCEND` is kept, and the app backs up the database before it migrates it.

## System requirements

| | |
|---|---|
| OS | Windows 10 or Windows 11, 64-bit (x64) |
| Runtime | Nothing extra: the engine (Python sidecar) ships inside the installer |
| Optional AI coach | [Ollama](https://ollama.com) with `ollama pull qwen3:4b` (about 2.5 GB; fits a 4 GB GPU, and runs on the CPU more slowly) |
| Internet | Not needed. Only the optional online exercise lookup (wger.de, Wikipedia) uses it, and only when you allow it |

## Verify the download

`SHA256SUMS.txt` is attached next to the installer, and GitHub shows each asset's SHA-256 digest.
In PowerShell:

```powershell
Get-FileHash .\ASCEND-Setup-1.0.0.exe -Algorithm SHA256
```

The hash must match the line for `ASCEND-Setup-1.0.0.exe` in `SHA256SUMS.txt`.

## Security fixes

1.0.0 contains every fix from the external code review of October 2026 (3 high, 6 medium and
22 low findings; the fixes first shipped in 0.4.0). The main ones:

- **Electron 45** (Electron 33 was out of support), with all nine Electron fuses set at pack time:
  no RunAsNode, no `NODE_OPTIONS` or `--inspect`, ASAR integrity on, app loaded only from
  `app.asar`. CI fails the build if a fuse is not set.
- **The engine ignores inherited settings.** The packaged sidecar no longer reads `ASCEND_*`
  variables from your environment, gets its token on stdin and only listens on `127.0.0.1`. The app
  checks a proof from the engine before it sends the token.
- **Safer restore and backups.** Only files from the backups folder are restored, after a size
  limit and a database integrity check; a broken backup file no longer breaks the list or the daily
  backup.
- **Tighter content security policy** (`connect-src 'self'`), a 30-second timeout on app requests
  and validation of export files.
- **Local AI stays local:** the Ollama address is normalised and must be on this PC unless you opt
  in.
- **Complete, re-importable exports**, with protection against CSV formula injection.
- **XP integrity:** editing or deleting sets re-prices XP and never raises it.
- **Supply chain:** release permissions limited to the publish job, every GitHub Action pinned to a
  commit, PyTorch 2.14.1 for the training pipeline.

The full table, with the test for each fix, is in [SECURITY.md](../../SECURITY.md).

## Known limitations

- **Unsigned installer.** SmartScreen warns until the project has a code-signing certificate.
- **Accuracy numbers come from simulated users.** The engines were evaluated on seeded synthetic
  users, not real people; the recovery correlation is partly circular because the simulator uses the
  same model family. See [docs/ai/evaluation.md](../ai/evaluation.md).
- **No food photo recognition in the app.** The food classifier pipeline exists in `ml/` but has
  only been trained and tested on synthetic smoke data (generated shapes, not food photos). Food is
  logged by search.
- **Local AI answers are not covered by tests.** The coach's model path is tested against a mocked
  Ollama; real `qwen3:4b` phrasing is checked by the number guard at run time.
- The adaptive TDEE needs a few weeks of weigh-ins and meals before it beats the formula.
- Workout programs are a fixed catalog; you cannot edit them yet.
- Backups are stored unencrypted in `%APPDATA%\ASCEND`; copy them to another drive yourself
  (SECURITY.md, L14).
- Food values are approximate; ASCEND is not medical or dietary advice.
